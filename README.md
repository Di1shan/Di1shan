| Area | What I practise in the lab |
| --- | --- |
| Network analysis | Capture traffic with Wireshark, identify services with Nmap, and investigate connectivity and DNS with traceroute, dig, and nslookup. |
| Web application security | Inspect HTTP requests and responses with Burp Suite and OWASP ZAP, study cross-site scripting (XSS), and explore how APIs handle repeated requests. |
| Static malware analysis | Examine PE headers and sections with PEview, inspect imports with Dependency Walker, extract strings with BinText, and check compiler or packer signatures with PEiD and Detect It Easy (DiE). |
| Dynamic malware analysis | Trace file and registry activity with Process Monitor, inspect process trees with Process Explorer, and check whether changes persist after reboot. |
| Reverse engineering | Step through Windows executables with OllyDbg and x64dbg, examine native code in Ghidra, and inspect .NET assemblies with dnSpy. |
| Digital forensics | Examine disk images in Autopsy and use The Sleuth Kit’s `icat` command to extract file contents. |
